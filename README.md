## Where to run it

The supported environment is **Noto** (`noto.epfl.ch`), reached with a UniNE account.
Colab and local installations work but are not supported.

## Data

Datasets live in [`data/`](data/README.md) and are loaded with a relative path, for example
`pd.read_csv("data/fund_prices.csv")`.
